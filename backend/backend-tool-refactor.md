@backend/ai_generator.py をリファクタリングして、Claudeが最大2回まで別々のAPIラウンドでツール呼び出しを行える「逐次ツール呼び出し」をサポートするようにしてください。

現在の挙動:
- Claudeが1回ツールを呼び出す → ツールはAPIパラメータから削除される → 最終的な応答
- Claudeが結果を見た後にもう一度ツール呼び出しをしたくても、それはできず（空の応答になる）

望ましい挙動:
- 各ツール呼び出しは個別のAPIリクエストで行われ、Claudeが前の結果を踏まえて推論できるようにする
- 複雑なクエリに対応できるようにする（比較のための複数検索、複数部分からなる質問、または異なるコース／レッスンから情報を取得する場合など）

例となるフロー:
1. ユーザー: 「コースXのレッスン4と同じテーマを扱っているコースを検索して」
2. Claude: コースXのアウトラインを取得 → レッスン4のタイトルを得る
3. Claude: そのタイトルを使って同じテーマを扱うコースを検索 → コース情報を返す
4. Claude: 完全な答えを提示する

要件:
- ユーザークエリにつき最大2回までの逐次ラウンド(sequential rounds)をサポートする
- 終了条件: (a) 2ラウンド完了、(b) Claudeの応答に tool_use ブロックが含まれていない、または (c) ツール呼び出しが失敗したとき
